ШПАРГАЛКА ДЛЯ КОМАНДЫ (Windows)
================================
Готовая БД: сырые таблицы + схема work (finding, evidence, v_abc).
Восстанавливается из дампа — CSV грузить не нужно.

1) Установить Docker Desktop:
   https://www.docker.com/products/docker-desktop/
   Перезагрузить ПК, дождаться Running (зелёный).

2) Распаковать архив, например в:
   C:\DS\spy_db_ready
   Внутри должны быть: docker-compose.yml, .env, dump\, sql\

3) PowerShell:
   cd C:\DS\spy_db_ready
   docker compose up -d

4) Первый запуск: 3–10 минут (restore дампа).
   Проверка:
   docker compose logs db
   Ищем строки:
     "Restore finished"
     "database system is ready to accept connections"
   Статус:
   docker compose ps
   → должно быть healthy / Up

5) DBeaver → New Connection → PostgreSQL:
   Host:     localhost
   Port:     5434
   Database: spy_flights
   User:     spy
   Password: spy
   → Test Connection → Finish

6) Что открыть в DBeaver (схемы):
   public  — сырые CSV (forum_*, skyteam_*, pointz_*, …)
   work    — анализ:
             work.v_abc      ← кандидаты A/B/C (начните отсюда)
             work.finding    ← находки (finding_type)
             work.evidence   ← доказательства
             work.flight     ← перелёты пассажира
             work.passenger  ← карты

Пример:
  SELECT * FROM work.v_abc
  WHERE risk_tier = 'A'
  ORDER BY suspicion_score DESC
  LIMIT 50;

--------------------------------
ЕСЛИ НЕ ЗАПУСКАЕТСЯ / ПОРТ ЗАНЯТ
--------------------------------
Признаки:
  - "port is already allocated" / "address already in use"
  - в DBeaver "role spy does not exist" (попали в чужой Postgres)

Что сделать:
  1. Открыть .env в Блокноте
  2. Поменять, например: SPY_PG_PORT=5435
  3. PowerShell:
       docker compose down
       docker compose up -d
  4. В DBeaver — ТОТ ЖЕ порт, что в .env

--------------------------------
ПОЛЕЗНЫЕ КОМАНДЫ
--------------------------------
  docker compose ps          # статус
  docker compose logs -f db  # логи
  docker compose down        # стоп (данные в Docker сохранятся)
  docker compose down -v     # стоп + УДАЛИТЬ данные (restore заново)

Не трогайте dump\ — это сама база в сжатом виде.
