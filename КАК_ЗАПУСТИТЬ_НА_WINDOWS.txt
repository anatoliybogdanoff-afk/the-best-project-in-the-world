ШПАРГАЛКА ДЛЯ КОМАНДЫ (Windows)
================================
Готовая БД: forum / skyteam / pointz + stage + feat (витрины person_features).
Восстанавливается из dump\spy_flights.dump — CSV грузить не нужно.

1) Docker Desktop:
   https://www.docker.com/products/docker-desktop/
   Перезагрузка ПК, статус Running.

2) Распаковать архив, например:
   C:\DS\spy_db_ready
   Нужны: docker-compose.yml, .env, dump\spy_flights.dump, sql\

3) PowerShell:
   cd C:\DS\spy_db_ready
   docker compose up -d

4) Первый запуск 3–10 минут. Проверка:
   docker compose logs db
   → "Restore finished"
   docker compose ps
   → healthy

5) DBeaver → PostgreSQL:
   Host localhost, Port 5434 (как в .env)
   Database spy_flights, User spy, Password spy

6) Схемы в DBeaver:
   forum, skyteam, pointz  — сырьё
   stage                   — промежуточное (flight_unique, person_anchor, …)
   feat                    — person_features, person_evidence, person, flight, card_conflict

   Сущность пользователя (ФИО, ДР, паспорта, карты):
   SELECT * FROM feat.person LIMIT 50;

   Каталог рейсов (сколько людей, страны):
   SELECT * FROM feat.flight ORDER BY people_n DESC LIMIT 50;

   Старт для отчёта по признакам:
   SELECT f.*, p.name_sirena, p.doc_passport_rf, p.cards
   FROM feat.person_features f
   JOIN feat.person p USING (person_id)
   WHERE f.card_multi_profile_n > 0 OR f.route_tail_rare_n > 0
   ORDER BY f.route_tail_rare_n DESC, f.card_multi_profile_n DESC
   LIMIT 50;

--------------------------------
ПОРТ ЗАНЯТ
--------------------------------
В .env: SPY_PG_PORT=5435
   docker compose down
   docker compose up -d
В DBeaver — тот же порт.

--------------------------------
КОМАНДЫ
--------------------------------
  docker compose down        # стоп, данные сохранены
  docker compose down -v     # стоп + удалить БД (restore заново)

Не удаляйте dump\ — это сама база.
